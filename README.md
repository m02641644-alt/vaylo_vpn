# 🤖 ربات فروش اشتراک فیلترشکن — پایتون (aiogram 3) برای هاست روی Railway

ربات کامل فروش VPN با مخزن کانفیگ، اکانت تست رایگان، کیف پول، کد تخفیف، رفرال،
پشتیبانی آنلاین (چت زنده)، عضویت اجباری چند‌کاناله، قوانین، و پنل مدیریت کامل —
همه با دکمه‌های شیشه‌ای (Inline).

> 🔒 توکن ربات و آیدی عددی ادمین **هیچ‌جای کد نیستن** — فقط از Environment Variables
> روی Railway خونده می‌شن. خیالت راحت باشه که این پروژه رو با هرکسی به اشتراک بذاری،
> اطلاعات حساس لو نمی‌ره.

---

## ✅ امکانات کامل

**سمت کاربر (همه با دکمه شیشه‌ای):**
- 🛒 خرید اشتراک با نمایش موجودی زنده (🟢 موجود / 🔴 ناموجود)
- 🎁 اکانت تست رایگان (هر کاربر فقط یک‌بار؛ وقتی موجودی تموم بشه پیام «به پایان رسید» می‌ده)
- 🎟 اعمال کد تخفیف روی هر پلن (درصدی یا مبلغ ثابت)
- 💳 پرداخت از کیف پول (تحویل آنی) یا 🏦 کارت‌به‌کارت (تایید ادمین + تحویل خودکار)
- 💳 کیف پول با حداقل/حداکثر مبلغ شارژ قابل‌تنظیم
- 🎁 سیستم رفرال با پاداش نقدی خودکار (قابل تنظیم از پنل)
- 📦 مشاهده‌ی سرویس‌های خریداری‌شده در هر لحظه
- 🛟 پشتیبانی آنلاین — چت زنده و دوطرفه با ادمین از داخل ربات
- 📋 قوانین و مقررات (متن قابل‌ویرایش)
- 📢 عضویت اجباری در یک یا چند کانال (قابل روشن/خاموش)

**پنل مدیریت کامل:**
- 📊 آمار کامل فروشگاه
- 🛍 مدیریت محصولات: افزودن محصول (نام/قیمت/مدت/حجم/توضیحات) و کنار هر محصول دو دکمه
  **🗃 مخزن** (افزودن کانفیگ‌های همون محصول، هرکدوم در یک خط) و **🗑 حذف**
- 🎁 مدیریت اکانت‌های تست رایگان (افزودن گروهی / حذف همه)
- 🧾 تایید/رد سفارش‌ها با یک کلیک (تحویل کاملاً خودکار پس از تایید)
- 👥 مدیریت کاربران: جستجو، افزایش/کاهش موجودی کیف پول، مسدودسازی
- 🎟 ساخت/حذف کد تخفیف (درصدی یا مبلغ ثابت، محدود به یک محصول یا همه، سقف تعداد استفاده)
- 📢 مدیریت کانال‌های عضویت اجباری (افزودن/حذف چند کانال)
- 📝 ویرایش تمام متن‌های ربات (خوش‌آمد، قوانین، پیام‌های سفارش و ...) با پشتیبانی از متغیر مثل `{name}`, `{price}`
- 💰 تنظیمات مالی: شماره کارت، نام صاحب کارت، حداقل/حداکثر شارژ، مبلغ و شرط رفرال
- 📣 ارسال پیام همگانی به همه‌ی کاربران

## 📁 ساختار پروژه

```
vpnbot-python/
├── bot.py                 # نقطه ورود اصلی
├── config.py               # خواندن متغیرهای محیطی
├── database.py              # لایه‌ی دیتابیس (SQLite)
├── texts.py                 # متن‌های قابل‌ویرایش ربات
├── keyboards.py              # کیبوردهای شیشه‌ای
├── states.py                 # حالت‌های مکالمه (FSM)
├── middlewares.py            # میان‌افزار ثبت کاربر و بررسی مسدودی
├── utils.py                  # توابع کمکی (فرمت پول، escape و ...)
├── handlers/
│   ├── common.py             # هندلرهای مشترک (بازگشت، لغو، بررسی عضویت)
│   ├── user.py                # هندلرهای سمت کاربر
│   └── admin.py                # هندلرهای پنل مدیریت
├── requirements.txt
├── Procfile                   # برای Railway
├── railway.json                # تنظیمات دیپلوی Railway
├── .env.example                # نمونه‌ی متغیرهای محیطی (مقدار واقعی رو اینجا نذار)
└── data/                        # محل دیتابیس SQLite (باید Volume بشه)
```

## 🚀 مراحل دیپلوی روی Railway

### ۱) ساخت ربات تلگرام
به [@BotFather](https://t.me/BotFather) پیام بده → `/newbot` → توکن رو نگه دار.
آیدی عددی خودت رو هم از [@userinfobot](https://t.me/userinfobot) بگیر.

### ۲) بالا بردن پروژه روی گیت‌هاب (پیشنهادی)
یک ریپازیتوری جدید (می‌تونه Private باشه) بساز و کل محتوای این پوشه رو داخلش push کن:
```bash
git init
git add .
git commit -m "vpn shop bot"
git branch -M main
git remote add origin <آدرس ریپوی تو>
git push -u origin main
```

### ۳) ساخت پروژه در Railway
1. به [railway.app](https://railway.app) برو و وارد شو
2. **New Project** → **Deploy from GitHub repo** → ریپازیتوری‌ای که ساختی رو انتخاب کن
3. Railway به‌صورت خودکار پایتون رو تشخیص می‌ده (Nixpacks) و طبق `railway.json` دستور
   `python bot.py` رو اجرا می‌کنه

> روش جایگزین بدون گیت‌هاب: نصب [Railway CLI](https://docs.railway.app/guides/cli)، سپس از
> داخل همین پوشه دستور `railway login` و بعد `railway up` رو بزن.

### ۴) تنظیم Variables (توکن و آیدی ادمین اینجا وارد می‌شن، نه در کد!)
داخل پروژه Railway → تب **Variables** → این دو مورد رو اضافه کن:

| Key | Value |
|---|---|
| `BOT_TOKEN` | توکنی که از BotFather گرفتی |
| `ADMIN_IDS` | آیدی عددی خودت (چند ادمین با کاما جدا کن، مثل `111111,222222`) |

(نیازی به تنظیم `DB_PATH` نیست، پیش‌فرضش `data/bot.db` است.)

### ۵) اتصال Volume برای نگه‌داری همیشگی دیتابیس ⚠️ خیلی مهم
فضای فایل روی Railway بین دیپلوی‌ها پاک می‌شه؛ برای اینکه اطلاعات کاربران/سفارش‌ها/موجودی از
بین نره:
1. در پروژه Railway → تب **Volumes** → **New Volume**
2. Mount Path رو بذار: `/app/data`
3. سرویس رو دوباره Deploy کن

از این به بعد پوشه `data/` روی یک دیسک دائمی ذخیره می‌شه و با هر آپدیت کد از بین نمی‌ره.

### ۶) بررسی نهایی
از تب **Deployments** → **View Logs** مطمئن شو خط مشابه زیر رو می‌بینی:
```
🤖 ربات با یوزرنیم @YourBotUsername شروع به کار کرد.
🚀 شروع دریافت پیام‌ها (polling)...
```
حالا به ربات تو تلگرام پیام `/start` بده — باید منوی شیشه‌ای رو ببینی. اگه آیدی‌ت رو درست
در `ADMIN_IDS` گذاشته باشی، دکمه‌ی «⚙️ پنل مدیریت» هم دیده می‌شه.

## 🧭 اولین قدم‌ها بعد از نصب

1. پنل مدیریت → **💰 تنظیمات مالی** → شماره کارت و نام صاحب کارت رو وارد کن
2. اگه عضویت اجباری می‌خوای: ربات رو ادمین کانالت کن، بعد از پنل →
   **📢 کانال‌های اجباری** → افزودن کانال، و در نهایت وضعیتش رو فعال کن
3. پنل → **🛍 مدیریت محصولات** → «افزودن محصول جدید» بزن (مثلاً «۵ گیگ یک ماهه»، قیمت، مدت،
   حجم، توضیحات) — بلافاصله بعدش ازت می‌خواد کانفیگ‌هاش رو وارد کنی (مخزن)
4. هر وقت خواستی به یه محصول موجودی اضافه کنی، از لیست محصولات دکمه‌ی **🗃 مخزن** کنارش رو بزن
5. پنل → **🎁 اکانت‌های تست** → چندتا اکانت تست اضافه کن تا کاربرا بتونن امتحان کنن
6. پنل → **🎟 کدهای تخفیف** → در صورت نیاز کد بساز
7. تمام! کاربرا می‌تونن بخرن و فوراً (کیف پول) یا بعد از تایید کارت‌به‌کارت، سرویس خودکار
   براشون ارسال می‌شه

## 💬 نکات درباره‌ی پشتیبانی آنلاین
- وقتی کاربر «🛟 پشتیبانی آنلاین» رو می‌زنه، هر پیامی (متن/عکس) که بفرسته مستقیم برای همه‌ی
  ادمین‌ها فوروارد می‌شه، همراه با دکمه‌ی «✍️ پاسخ به کاربر»
- با زدن این دکمه، هر پیامی که ادمین از اون لحظه بفرسته مستقیم برای همون کاربر ارسال می‌شه
- برای پایان چت، ادمین دستور `/done` رو بفرسته یا کاربر دکمه‌ی «🔴 پایان گفتگو» رو بزنه

## ⚠️ نکات مهم

- **دیتابیس SQLite:** برای چند صد تا چند هزار کاربر عالیه. اگه فروشگاه خیلی بزرگ بشه،
  می‌تونی بعداً به PostgreSQL مهاجرت کنی (ساختار کد به‌گونه‌ای تمیزه که این کار راحته).
- **بکاپ:** هر از گاهی فایل `data/bot.db` رو از Volume دانلود و بکاپ بگیر (از تب Volumes
  در Railway قابل مدیریت است) یا اسکریپت بکاپ خودکار اضافه کن.
- **رمزها/توکن:** هیچ‌وقت مقدار واقعی `BOT_TOKEN` یا `ADMIN_IDS` رو داخل کد یا فایل
  `.env` وارد‌شده به گیت‌هاب public قرار نده؛ `.gitignore` همین پروژه فایل `.env` رو
  نادیده می‌گیره.
- بعد از هر تغییر در کد و push به گیت‌هاب، Railway به‌صورت خودکار دوباره دیپلوی می‌کنه.

## 🛠 عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| ربات اصلاً روشن نمی‌شه / کرش می‌کنه | از Logs بخون؛ اگه `BOT_TOKEN تنظیم نشده` می‌بینی، Variables رو چک کن |
| بعد از هر دیپلوی، کاربرا/سفارش‌ها پاک می‌شن | Volume رو طبق مرحله ۵ وصل نکردی |
| دکمه‌ی پنل مدیریت دیده نمی‌شه | آیدی عددیت تو `ADMIN_IDS` اشتباهه (باید عدد باشه نه یوزرنیم) |
| بعد از خرید، کانفیگ نمیاد | موجودی اون محصول در «🗃 مخزن» صفره؛ اضافه کن |
| پیام «عضو کانال بشو» همیشه میاد | ربات رو ادمین کانال نکردی، یا آیدی کانال اشتباه واردشده |
| کد تخفیف قبول نمی‌شه | چک کن کد رو درست تایپ کرده (case-insensitive هست)، سقف استفاده یا محدودیت محصول رو هم ببین |
